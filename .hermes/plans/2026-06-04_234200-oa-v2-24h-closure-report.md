## 关键经验

1. **subagent 25 次 tool 上限**: 大模块要拆, 每个限定 ≤12 次
2. **`git add -A <path>` 风险**: 会捎带 untracked 邻居文件, 要先 `git status` 确认范围
3. **soft reset 是拆 commit 的安全武器** (hard reset 才禁止)
4. **mvn 编译输出含中文会触发 grep "binary file matches"**, 加 `-a` 强 text
5. **patch 工具 partial-view 警告**: 修小改动可以, 但要信任前一次 read (用 search_files 看 context 行比 read_file 全文更省上下文)
6. **subagent interrupt 不是失败**: 看 reflog/git log 确认实际成果再决定继续
