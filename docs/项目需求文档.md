## 1. 系统概述

### 1.1 系统定位

企业办公自动化系统，覆盖行政、文档、财务、人事、知识、消息、任务、工作流、考勤、报表、排程、薪资、预警告警等 **12+ 业务域**。系统面向企业内部员工和管理者，提供一站式办公协同能力。

### 1.2 系统范围

| 维度 | 范围 |
|------|------|
| 用户规模 | 200-5000 人 |
| 终端 | PC 管理后台 + 移动端 H5 + 微信小程序 |
| 部署模式 | 私有化部署 |
| 当前版本明确不做 | 分布式事务、MQ 队列、ES 全文检索、多租户、i18n、移动端原生 App |

### 1.3 用户角色

| 角色 | 描述 | 覆盖人数 |
|------|------|---------|
| 普通员工 (USER) | 提交申请、查看信息、个人操作 | 全员 |
| 组长 (TEAM_LEAD) | 基层审批、团队管理 | 部门内分组负责人 |
| 部门经理 (DEPT_MANAGER) | 部门级审批、部门管理 | 各部门负责人 |
| 总监 (DIRECTOR) | 跨部门/大额审批 | 高层管理 |
| 总经理 (GM) | 最终审批 | 总经理办公室 |
| 系统管理员 (ADMIN) | 系统配置、权限管理、监控 | IT 管理员 |

## 3. 详细功能需求

### 3.1 系统管理

#### 3.1.1 用户管理
- **功能描述**：管理系统所有用户账号
- **功能点**：
  - 用户列表（分页、搜索、导出）
  - 新增用户（工号、姓名、部门、岗位、角色）
  - 编辑用户信息
  - 重置密码（默认 `123456`）
  - 启用/停用账号
  - 删除用户（逻辑删除）
- **权限**：仅 ADMIN

#### 3.1.2 部门管理
- **功能描述**：管理企业组织架构树
- **功能点**：
  - 部门树展示（支持多级树结构）
  - 新增/编辑/删除部门
  - 部门负责人设置
  - 同级排序
- **权限**：仅 ADMIN

#### 3.1.3 角色管理
- **功能描述**：定义系统角色及其权限
- **功能点**：
  - 角色列表（CRUD）
  - 为角色分配菜单权限
  - 角色数据权限范围
- **权限**：仅 ADMIN

#### 3.1.4 菜单管理
- **功能描述**：维护系统菜单树和功能权限点
- **功能点**：
  - 树形菜单展示
  - 新增/编辑/删除菜单项
  - 菜单类型（目录/菜单/按钮）
  - 权限标识设置（如 `sys:user:create`）
  - 图标选择（Element Plus 图标全量注册）
  - 路由地址与组件路径
  - 排序与显隐控制
- **权限**：仅 ADMIN

#### 3.1.5 字典管理
- **功能描述**：维护系统字典数据（请假类型、审批状态等）
- **功能点**：
  - 字典类型管理（CRUD）
  - 字典数据管理（CRUD）
- **权限**：仅 ADMIN

#### 3.1.6 参数配置
- **功能描述**：系统级参数配置
- **功能点**：键值对配置管理
- **权限**：仅 ADMIN

### 3.2 人事管理

#### 3.2.1 员工档案
- **功能描述**：管理员工基本信息、入职信息、合同信息
- **功能点**：
  - 档案列表（分页、搜索）
  - 新增/编辑/查看档案
  - 档案导入导出（EasyExcel）
- **权限**：ADMIN / HR 相关人员

#### 3.2.2 岗位管理
- **功能描述**：维护企业岗位体系
- **功能点**：岗位 CRUD
- **权限**：ADMIN

#### 3.2.3 薪资管理
- **功能描述**：管理薪资结构和薪资记录
- **功能点**：
  - 薪资结构定义
  - 薪资记录查看
  - 个人薪资查询
- **权限**：ADMIN、本人

### 3.3 考勤管理

#### 3.3.1 打卡签到
- **功能描述**：员工上下班打卡
- **功能点**：
  - GPS 定位打卡
  - 打卡时间记录
  - 迟到/早退/缺卡标记
  - Redis 打卡去重（24h TTL）
- **权限**：全员

#### 3.3.2 考勤统计
- **功能描述**：查看考勤记录和统计报表
- **功能点**：
  - 个人考勤日历
  - 月度考勤统计
  - 管理员查看全员的考勤报表
- **权限**：全员（个人）、ADMIN/DEPT_MANAGER（部门）

#### 3.3.3 考勤组管理
- **功能描述**：配置考勤规则和分组
- **功能点**：
  - 考勤组 CRUD
  - 配置上下班时间
  - 配置打卡地点
  - 配置考勤人员
- **权限**：ADMIN

### 3.4 财务管理

#### 3.4.1 预算管理
- **功能描述**：部门/项目预算编制与执行跟踪
- **功能点**：
  - 预算编制
  - 预算执行监控
  - 预算调整
- **权限**：视角色而定

#### 3.4.2 费用报销
- **功能描述**：员工费用报销申请与审批
- **功能点**：
  - 提交报销申请（含金额）
  - 分级审批（≤5000经理；5000-50000总监；>50000总经理）
  - 报销状态跟踪
- **权限**：全员（申请）、逐级审批

#### 3.4.3 借款管理
- **功能描述**：员工借款申请与还款
- **功能点**：
  - 借款申请
  - 分级审批（同报销金额阶梯）
  - 借款余额
  - 还款记录
- **权限**：全员（申请）、逐级审批

### 3.5 工作流引擎

#### 3.5.1 流程定义管理
- **功能描述**：可视化和 JSON 配置方式管理审批流程
- **功能点**：
  - 流程定义列表
  - 创建/编辑流程定义（JSON 格式）
  - 流程设计器（@vue-flow 可视化）
  - 激活/停用流程版本
  - 流程校验与预览
- **架构**：
  - Schema v2：基础图结构（nodes + edges）
  - Schema v3：增加自定义运行时配置
  - 遗留 schema：扁平数组定义
- **权限**：ADMIN

#### 3.5.2 分级审批路由

| 业务 | 路由维度 | 阈值 | 审批层级 |
|------|---------|------|---------|
| 请假 | 天数 | ≤7 / >7 | 部门经理 → 总监 |
| 出差 | 天数 | ≤7 / >7 | 部门经理 → 总监 |
| 外出 | 天数 | ≤7 / >7 | 部门经理 → 总监 |
| 加班 | 小时 | ≤36 / >36 | 部门经理 → 总监 |
| 采购 | 金额 | ≤5000 / 5000-50000 / >50000 | 经理 → 总监 → 总经理 |
| 报销 | 金额 | ≤5000 / 5000-50000 / >50000 | 经理 → 总监 → 总经理 |
| 借款 | 金额 | ≤5000 / 5000-50000 / >50000 | 经理 → 总监 → 总经理 |

#### 3.5.3 审批操作
- 通过（可填写审批意见）
- 驳回（填写驳回原因）
- 转办（转给其他人审批）
- 退回（退回到指定节点）
- 催办（提醒审批人）
- 撤回（申请人撤回申请）
- 会签（多人同时审批）
- 或签（任一人通过即可）
- 委托（将审批权委托给他人）

#### 3.5.4 超时处理机制
| 超时动作 | 描述 |
|---------|------|
| escalate | 升级到更高级审批人 |
| notify_only | 仅发送通知提醒 |
| auto_reject | 自动拒绝流程 |

## 4. 角色与权限矩阵

### 4.1 角色定义

| 角色标识 | 角色名称 | 说明 |
|---------|---------|------|
| ADMIN | 超级管理员 | 系统全部权限，通配符 `*:*:*` |
| GM | 总经理 | 最终审批权限 |
| DIRECTOR | 总监 | 跨部门/大额审批 |
| DEPT_MANAGER | 部门经理 | 部门级审批管理 |
| TEAM_LEAD | 组长 | 团队级审批管理 |
| USER | 普通用户 | 基础操作权限 |

### 4.2 权限码格式

```
{业务域}:{资源}:{操作}
```

示例：
- `hr:employee:create` — 创建员工
- `hr:employee:update` — 编辑员工
- `hr:employee:delete` — 删除员工
- `attendance:checkin` — 打卡签到
- `leave:apply` — 提交请假
- `leave:approve` — 审批请假
- `sys:user:list` — 查看用户列表
- `sys:role:create` — 创建角色

### 4.3 权限控制机制

- 控制层使用 `@RequirePermission("domain:resource:action")` 注解
- 使用 `@RequireRole("DEPT_MANAGER")` 注解限定角色
- 使用 `@RequireAdmin` 注解限定管理员
- 权限数据通过 `PermissionResolver` 从 Redis/DB 解析
- ADMIN 角色拥有 `*:*:*` 通配符权限

## 5. 业务流程定义

### 5.1 核心审批业务流程

```
员工提交申请 → 工作流引擎路由 → 第一级审批 → (如果满足升级条件) → 第二级审批 → ... → 流程结束
                        ↓                          ↓
                    驳回（退回申请人）          业务回调（更新额度/状态）
```

### 5.2 请假流程

```
开始 → 部门经理审批 → 网关(请假天数) → [>7天] → 总监审批 → 结束
                                  → [≤7天] → 结束
```

### 5.3 采购/报销/借款流程

```
开始 → 部门经理审批 → 网关(金额) → [5000-50000] → 总监审批 → 网关(金额) → [>50000] → 总经理审批 → 结束
                                 → [≤5000] → 结束                    → [≤50000] → 结束
```

## 6. 非功能需求

### 6.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 3秒（首屏） |
| API 响应时间 | < 500ms（95% 请求） |
| 并发用户数 | 支持 500 并发 |
| 数据库连接池 | 20-50 |

### 6.2 安全需求

| 类别 | 要求 |
|------|------|
| 身份认证 | JWT（jjwt 0.12.5），2h 过期 |
| 密码加密 | BCrypt（Hutool） |
| 访问控制 | RBAC，细粒度到按钮级 |
| 登录保护 | 验证码 + IP 限流（5次/60秒） |
| 请求校验 | `@Validated` 参数校验 |
| SQL 防护 | MyBatis-Plus 参数绑定，无 SQL 拼接 |

### 6.3 数据需求

| 类别 | 要求 |
|------|------|
| 逻辑删除 | `del_flag` 字段（'0'正常/'1'已删） |
| 数据审计 | `create_by/time`, `update_by/time` 自动填充 |
| 乐观锁 | `@Version` 字段 `version` |
| 数据唯一性 | 业务唯一键 + 数据库约束 |

### 6.4 可用性需求

| 类别 | 要求 |
|------|------|
| 系统可用性 | 99.5%（非工作时间除外） |
| 备份策略 | 数据库每日全量备份 |
| 故障恢复 | < 30 分钟 |
