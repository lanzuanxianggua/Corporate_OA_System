# 企业OA办公系统 — Figma 设计提示词

## 设计规范

### 设计系统基础参数

```
设计尺寸：1440 × 900（桌面端 Web 后台管理系统标准尺寸）
色彩系统：
  - 主色：#409EFF（Element Plus 默认蓝，用于按钮/链接/高亮/选中态）
  - 成功：#67C23A（正常出勤/审批通过）
  - 警告：#E6A23C（迟到/待审批）
  - 危险：#F56C6C（缺勤/已拒绝）
  - 信息：#909399（辅助文字）
  - 背景色：#F5F7FA（页面底色）
  - 卡片色：#FFFFFF
  - 文字主色：#303133
  - 文字次色：#606266
  - 文字辅色：#909399
  - 边框色：#EBEEF5
  - 侧边栏背景：#FFFFFF（浅色主题）

字体：中文用 "PingFang SC" / "Microsoft YaHei"，英文用 "Inter" / "Helvetica Neue"
  - 页面标题：18px Bold（#303133）
  - 卡片标题：16px Medium（#303133）
  - 正文：14px Regular（#606266）
  - 辅助文字：13px Regular（#909399）
  - 表格内容：14px Regular
  - 小标签：12px Regular

间距系统：4px 基准（4/8/12/16/20/24/32）
圆角：4px（按钮/输入框），8px（卡片），12px（统计卡片/大卡片）
阴影：0 2px 12px rgba(0,0,0,0.06)（卡片浮起感）
```

### P1. 登录页（login/index.vue）

**提示词：**
```
设计一个企业OA系统的登录页面，居中卡片式布局。

整体布局：
- 背景：浅灰色渐变底色，左侧放一张装饰性插画（抽象几何图形/办公场景）
- 右侧居中放置登录卡片，宽 420px，白色圆角 12px，带阴影

登录卡片内容：
- 顶部：OA 图标 + "OA 办公系统" 标题
- 表单区域：
  - 用户名输入框（前置用户图标，placeholder "请输入用户名"）
  - 密码输入框（前置锁图标，placeholder "请输入密码"，带显示/隐藏切换）
  - "记住我" 复选框
  - 登录按钮（满宽，主色 #409EFF，圆角 4px，hover 加深）

设计风格：简洁现代，企业级后台风格，无多余装饰。
```

## 在 Figma 中开始设计的步骤

### 第一步：创建项目

1. 打开 Figma → 点击 "New design file"
2. 重命名为 "企业OA系统 - UI设计"
3. 设置画布尺寸：每个页面创建一个 Frame，尺寸 `1440 × 900`

### 第二步：创建设计系统组件

在开始画页面前，先建一个 "Design System" 页面（Figma 左侧 Page 标签），包含：

1. **颜色变量（Variables）**：建立 Color tokens（primary/success/warning/danger/text/bg 等）
2. **文字样式（Text Styles）**：创建 h1/h2/body/small 等文字样式
3. **基础组件（Components）**：
   - 按钮：主要/成功/警告/危险（默认/hover/disabled 态）
   - 输入框：默认/focus/disabled/error 态
   - 下拉选择器
   - 日期选择器
   - 表格：表头行 + 数据行（奇偶色）
   - 标签 Tag：各颜色
   - 卡片 Card：白色圆角带阴影
   - 分页器
   - 对话框 Dialog
   - 空状态插图
   - 统计数字卡片

### 第三步：按角色分组设计页面

在 Figma 中创建多个 Page 标签页分组：

```
📁 Design System     ← 颜色/字体/基础组件
📁 00-Login           ← 登录页
📁 01-User-Pages      ← 员工端页面（P2/P4/P7/P8/P10/P12/P14/P16/P17/P18/P27）
📁 02-Admin-Pages     ← 管理员页面（P3/P6/P9/P11/P13/P15/P19/P20-P23/P24-P26）
📁 03-Error           ← 错误页
```

### 第四步：使用 Auto Layout

- 所有卡片、表格、表单使用 **Auto Layout**（Shift+A），确保布局弹性
- 水平间距用 **Gap** 控制（16px/20px/24px）
- 响应式考虑：内容区宽度 = 1440 - 侧边栏(210) - 内边距(40)

### 第五步：交互原型

- 在 Figma 的 Prototype 模式中，连接页面跳转
- 侧边栏菜单项点击 → 跳转对应页面
- 按钮点击 → 弹出对话框
- 使用 **Interactive Components** 制作按钮 hover/active 状态

### 第六步：交付给 Claude Code

设计完成后，在 Figma 中选中要实现的页面 Frame，复制链接，然后告诉 Claude Code：

```
请根据这个 Figma 设计实现前端页面：https://www.figma.com/design/xxxxx/...?node-id=xxxx
```

Claude Code 会通过 Figma MCP 读取设计稿的布局、颜色、间距等，自动生成对应的 Vue 3 + Element Plus + Tailwind CSS 代码。
