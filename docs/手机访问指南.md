## 📍 第一步：确定你的电脑局域网 IP

### Windows 系统查看方法：

打开命令提示符（CMD）或 PowerShell，输入：
```bash
ipconfig
```

在输出结果中找到**正在使用的网络适配器**，记下其 IPv4 地址。

### 常见局域网 IP 段：
- `192.168.x.x` — 家庭路由器、小型办公网络
- `10.x.x.x` — 公司/校园网络
- `172.16.x.x ~ 172.31.x.x` — 部分企业内网

**你的电脑可能的局域网 IP**：`10.197.244.2`

## ⚠️ 常见问题与解决方案

### 1. 手机无法访问（连接超时）

**原因**：防火墙阻止了外部设备访问

**解决方法**：

#### Windows 防火墙设置：

**方式A：关闭防火墙（临时测试用）**
1. 打开"控制面板" → "Windows Defender 防火墙"
2. 点击左侧"启用或关闭 Windows Defender 防火墙"
3. 将"专用网络设置"和"公用网络设置"都选择为"关闭"
4. 点击"确定"

**方式B：添加入站规则（推荐）**
1. 打开"控制面板" → "Windows Defender 防火墙" → "高级设置"
2. 点击左侧"入站规则"
3. 点击右侧"新建规则"
4. 选择"端口" → 下一步
5. 选择"TCP"，输入特定本地端口：`8080, 8848` → 下一步
6. 选择"允许连接" → 下一步
7. 勾选"域"、"专用"、"公用" → 下一步
8. 输入名称：`OA系统局域网访问` → 完成

---

### 2. 显示 CORS 跨域错误

**原因**：后端 CORS 配置未生效

**解决方法**：
- 确认后端已重启（PID: 28848）
- 检查后端日志，确认配置已加载
- 清除浏览器缓存后重试

---

### 3. 前端样式错乱或白屏

**原因**：前端静态资源加载失败

**解决方法**：
- 使用 Chrome 浏览器（推荐）
- 清除手机浏览器缓存
- 检查手机网络信号强度

---

### 4. 手机与电脑不在同一网络

**解决方法**：
- 手机连接与电脑相同的 Wi-Fi
- 如果电脑用网线，确保网线和 Wi-Fi 属于同一路由器

## 🌐 后端已支持的访问来源

当前 CORS 配置允许以下来源访问：
- `http://localhost:*` — 本地回环
- `http://127.0.0.1:*` — 本地回环
- `http://10.*:*` — 10.x.x.x 网段（公司/校园网）
- `http://192.168.*:*` — 192.168.x.x 网段（家庭路由器）
- `http://172.*:*` — 172.x.x.x 网段（企业内网）
